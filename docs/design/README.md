# TRAPSTATION OS – design reference / Designreferenz

The approved Workstation design: **154 views** of 51 pages and 17 machines, in three groups.

| Group | Views | What |
| --- | ---: | --- |
| A / Workspace | 81 | Start-up, start menu, banks, saving, sequencer, piano roll, mixer, effects, performance, clock, navigation, dialogs |
| B / MIDI tools | 11 | The four generators, scale, arp, chord, chord gen, chord var, quick fill, Euclid |
| C / Instruments | 62 | Sound editing, all 17 machines, the sampler's knob sets and slices |

- [index.html](index.html): searchable gallery of every view (open it in the browser)
- [Designkarte-Alle-Ansichten.png](Designkarte-Alle-Ansichten.png): all views on one sheet ·
  [Finale-Auswahl.png](Finale-Auswahl.png): the compact overview
- [boards/](boards/): eight boards at native size · [png/](png/) and [svg/](svg/): every view on its own
- [motion/Final-Startup.gif](motion/Final-Startup.gif): the start-up animation · [clock.html](clock.html): the clock page in motion

The views show example values; several views can be states of the same page. How to use each page: [docs/manual](../manual/).
